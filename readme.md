# Full Stack Docker Project — Spring Boot + React + MySQL

Projet Full Stack réalisé avec :

- Spring Boot 3
- ReactJS
- MySQL
- Docker
- Docker Compose

Le projet permet la gestion des voitures via une API REST et une interface React moderne.

# Technologies utilisées

## Backend
- Java 21
- Spring Boot 3
- Spring Data JPA
- Spring Data REST
- Spring Security
- Swagger / OpenAPI
- Maven

## Frontend
- ReactJS
- Axios
- React Bootstrap
- React Router

## Base de données
- MySQL 8

## DevOps
- Docker
- Docker Compose
